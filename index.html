S

Situation · 상황

Python의 if, else 조건문을 배우면서 로그의 상태와 기록 개수에 따라 서로 다른 결과를 출력하는 과제를 진행했습니다. 이후 for 반복문을 학습하며 여러 값에 같은 조건을 적용하는 문제를 풀었습니다.

T

Task · 과제

Network-002에서는 FAIL 기록을 구별하고 기록 개수가 기준값 이상인지 판단하고자 했습니다. Network-004에서는 리스트에서 3 이상인 값만 찾고, 조건에 맞는 값의 개수와 합계를 각각 계산하고자 했습니다.

A

Action · 행동

Network-002에서는 if, else와 비교 연산자를 활용해 코드를 작성했습니다. 처음에는 여러 문제를 하나의 Python 파일에 작성했지만, 과제 요구사항을 다시 확인하고 F1과 F2를 각각의 파일로 분리했습니다.

Network-004에서는 for 반복문과 if 조건문을 함께 사용해 F1과 F2 코드를 작성했습니다. 리스트의 값 중 3 이상인 숫자의 개수와 합계를 구하고, 첫 번째 값을 0에서 7로 변경한 뒤 다시 실행했습니다.

AI에게 코드의 실행 흐름과 Git 명령어의 역할을 질문하고, 변경된 파일과 학습 기록을 직접 확인한 후 GitHub에 커밋하고 푸시했습니다.

R

Result · 결과

Network-002의 F1과 F2 코드를 별도 파일로 정리하고, 학습 기록과 함께 GitHub에 게시했습니다. Git 명령어와 GitHub 웹사이트를 통해 업로드한 파일을 확인했습니다.

Network-004에서는 counts의 첫 번째 값을 0에서 7로 변경한 결과, 3 이상인 숫자가 7, 4, 5로 총 3개이고 합계가 16이라는 것을 확인했습니다. 실제 출력값은 3 16이었습니다. 이 과정에서 반복문으로 여러 값을 검사하고, 조건문으로 필요한 값만 선택해 개수와 합계를 계산하는 방법을 익혔습니다.
