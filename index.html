S

Situation · 상황

SKT ALEPH 교육 과정에서 Python을 활용해 코드 외부의 파일을 생성하고 읽는 방법을 학습했습니다. 특히 텍스트 파일과 CSV 형식의 로그를 다루면서 파일 입출력과 예외 처리의 기본적인 동작을 실습했습니다.

T

Task · 과제

파일을 생성하고 내용을 기록한 뒤 다시 읽어 결과를 확인하는 것이 목표였습니다. 또한 기존 파일에 내용을 추가하고, 로그에서 특정 사용자의 기록만 검색하며, 존재하지 않는 파일을 열었을 때 발생하는 오류를 처리하는 과제를 수행했습니다.

A

Action · 행동

with open()을 사용해 파일을 열고, w, a 모드로 내용을 쓰거나 추가했습니다. read()와 for 반복문으로 파일을 읽고, strip()으로 줄바꿈 문자를 제거했습니다.

sample_logs.csv에 6개의 로그를 작성하고, in 연산자를 이용해 park03이 포함된 기록만 검색했습니다. F1에서는 check.txt 파일에 점검시작과 점검 끝을 기록한 뒤 다시 읽었습니다.

F2에서는 존재하지 않는 not-provided.txt를 열도록 코드를 작성하고, try-except로 FileNotFoundError를 처리했습니다. 실습 과정에서 AI의 도움으로 코드 오류 원인과 파일 입출력 개념을 확인하고, 직접 코드를 수정하고 실행 결과를 검증했습니다.

R

Result · 결과

파일 생성과 읽기, 내용 추가가 정상적으로 동작하는 것을 확인했습니다. 총 6개의 로그 중 park03이 포함된 2개의 기록을 선택해 출력했습니다.

check.txt에 작성한 점검 기록을 다시 읽어 확인했으며, 없는 파일을 열었을 때 '파일 위치를 확인하세요'라는 안내 문구가 정상 출력되는 것을 확인했습니다. 이를 통해 파일 입출력과 예외 처리를 함께 활용하는 방법을 익혔습니다.

S

Situation · 상황

SKT ALEPH 교육 과정에서 VS Code의 Python 실행환경을 점검하고, 잘못된 입력이 발생했을 때 프로그램이 중단되지 않도록 예외 처리하는 방법을 학습했습니다.

T

Task · 과제

Python 가상환경과 필요한 패키지를 확인하고, try-except를 사용해 숫자로 변환할 수 없는 값과 존재하지 않는 리스트 항목을 처리하고자 했습니다. 또한 반복문에서 잘못된 값을 건너뛰고 정상적인 값만 더하는 과제를 수행했습니다.

A

Action · 행동

VS Code에서 .venv 인터프리터를 선택하고, settings.json을 수정하여 코드 자동완성 기능을 비활성화했습니다. 설정 과정에서 누락된 쉼표로 발생한 JSON 문법 오류도 수정했습니다.

F1에서는 문자열 "abc"를 정수로 변환할 때 발생하는 ValueError를 try-except로 처리했습니다. F2에서는 ["2", "bad", "3"]을 반복하며 숫자로 변환할 수 없는 값을 건너뛰고 합계를 구하는 코드를 작성했습니다.

R1에서는 예외 발생 후 코드의 실행 순서를, R2에서는 IndexError 처리 방법을 학습했습니다. 두 복습 문제는 별도 파일을 만들지 않고 assignment_05_f2.py에서 실습했습니다.

R

Result · 결과

try-except를 사용하면 잘못된 데이터가 있어도 오류를 처리하고 다음 작업을 이어갈 수 있다는 점을 이해했습니다. ValueError와 IndexError가 발생하는 상황을 구분하고, 반복문과 예외 처리를 함께 활용하는 방법을 학습했습니다.

또한 VS Code에서 Python 실행환경을 확인하고, 터미널 경로와 코드 설정을 직접 점검하는 방법을 익혔습니다.

Action · 행동

Network-002에서는 if, else와 비교 연산자를 활용해 코드를 작성했습니다. 처음에는 여러 문제를 하나의 Python 파일에 작성했지만, 과제 요구사항을 다시 확인하고 F1과 F2를 각각의 파일로 분리했습니다.

AI에게 코드의 실행 흐름과 Git 명령어의 역할을 질문하고, 변경된 파일과 학습 기록을 직접 확인한 후 GitHub에 커밋하고 푸시했습니다.
