Swift Playgrounds로 익히는 프로그래밍 기초

MacBook 환경에서 Swift Playgrounds를 활용해 프로그래밍 기초를 학습했습니다. AI에게 질문하고 직접 코드를 작성하며, 문제 해결 과정과 학습 내용을 기록하고 있습니다.

01

학습 목표

  • 변수와 점 표기법의 역할 이해하기
  • if 조건문과 for 반복문으로 실행 흐름 파악하기
  • func와 매개변수를 활용해 동작을 묶어 표현하기
  • 직접 작성한 코드의 실행 과정을 설명하고 개선점 확인하기
02

STAR 학습 사례

2026.10.23 · Swift Playgrounds

반복문과 함수를 활용한 캐릭터 이동 코드 작성

S

Situation · 상황

변수, 조건문, 반복문을 익힌 뒤 함수를 정의하고 사용하는 단계에서 학습했습니다.

T

Task · 과제

입력한 횟수만큼 캐릭터를 이동시키고, 이동 후 방향을 한 번 전환하는 코드를 구성하고자 했습니다.

A

Action · 행동

AI에게 매개변수와 반복문의 실행 구조를 질문하고, 실행 횟수를 예측하는 연습을 했습니다. 직접 for i in 1...steps 반복문을 작성하고 회전 명령을 반복문 밖에 두었습니다. AI의 피드백으로 메서드 이름의 대소문자 오류를 확인했습니다.

R

Result · 결과

함수 호출, 반복문, 조건문에 따른 이동 및 회전 횟수를 계산하는 연습 문제를 해결했습니다. 이동과 회전을 구분한 코드 구조를 직접 작성했으며, Swift의 대소문자 구분 규칙을 확인했습니다.

기록 범위: 수정된 코드를 실제 퍼즐에서 다시 실행해 성공했는지는 확인되지 않아 성과로 기재하지 않았습니다.
